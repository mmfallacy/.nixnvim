# Partial staging

Prefer `git add -- <exact files>` when each entire file belongs to the approved group. Use explicit file paths only: no `git add .`, `-A`, globs, or directory paths. For a tracked file shared across groups, inspect its complete diff and choose hunks only when both the staged slice and the remaining work are coherent. For example, a test file may have declaration tests needed with a new declaration and assembly tests needed later with the assembler; stage the declaration tests now, leave assembly tests for that later group. Do not stage tests that fail solely because their behavior is still unstaged.

Verified index-only method: `git add -p -- <exact tracked file>` uses Git's patch selector without rewriting a patch or touching the worktree. The shell tool can supply a short, quoted heredoc of `y`/`n` choices to its stdin; first review `git diff --no-ext-diff -- <exact file>` and match each Git-displayed hunk to the approved scope. Git shows each candidate patch with headers and context. Accept only understood hunks; if Git combines two behaviors into one inseparable hunk, or the selection cannot be checked confidently, stop and ask for the file to be split by an editing agent. Do **not** manually reproduce a large file as a patch in the conversation. Do not apply a patch to the worktree.

After staging, inspect `git status --short`, `git diff --cached --check`, and the complete `git diff --cached --no-ext-diff`; compare `git diff --no-ext-diff -- <split files>` against the planned remainder. The cached diff must be exactly the approved group, and both slices must be independently valid in commit order. If selection or verification fails after any staging, stop and tell the user what happened; do not silently unstage or alter their files.

**Scenario — declaration test now, assembly test later:** After approval, stage `src/declaration.ts` as a whole file. In `tests/widget.test.ts`, Git presents one declaration hunk and one assembly hunk: select the former and reject the latter. Verify the cached diff contains the declaration and its test only, while the unstaged diff still contains the assembly test. If Git presents one combined hunk, stop and request a code split instead of copying the test file into a hand-written patch.
